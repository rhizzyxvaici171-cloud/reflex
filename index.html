How this is measured

  • Reaction time is timed with performance.now(), not Date.now(), for sub-millisecond precision unaffected by system clock adjustments. A click before the color changes is scored as a false start, not a fast time.
  • Sequence memory grows by one step every successful round. The game ends on the first wrong tile, with the longest completed sequence recorded as the result.
  • Personal bests are saved in this browser only, via localStorage. Nothing is sent anywhere.
